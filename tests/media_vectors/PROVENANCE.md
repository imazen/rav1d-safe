# Synthetic AV1 packet fixture

`av1-10-420-full-17x13.ivf` contains four original synthetic lossless frames.
No external artwork, photographs, or training data were used. Generated by
`zenmedia/scripts/generate_av1_corpus.py` and independently decoded through
FFmpeg's libdav1d; every output sample equals the source generator.

The source sample for frame f, component p and coordinate (x,y) is:
`level = (17*x + 29*y + 43*f + 71*p) % 257`, except the top-left
sample is 0 on even frames and 256 on odd frames;
`sample = (1023*level + 128)/256` with integer division.
Chroma dimensions use ceiling division.
