dav1d 1.1.0 -> 1.5.1 PERFORMANCE CHANGES (research 2026-05-25)
Primary source: dav1d NEWS via GitHub raw (videolan/dav1d), Phoronix, jbkempf.com blog, GitLab MR titles.
rav1d-safe vendored asm from dav1d 1.0.0; latest dav1d = 1.5.1.

=== BASELINE: what AVX-512 already existed at dav1d 1.0.0 (vendored) ===
AVX-512 (ICL) present by 0.6.0 / 1.0.0 for 8bpc: prep_bilin, prep_8tap, cdef_filter,
mc_avg/w_avg/mask. So rav1d-safe's vendored asm ALREADY had AVX-512 for 8bpc mc + cdef.
The 8-bit AVX-512 ICL push (MR !1301 et al) and itx landed around 1.0 timeframe.

=== KEY ISA MAGNITUDES (from articles/MRs) ===
- AVX-512 ICL mc 8-tap: ~1.5x-2x faster than AVX2 per width (FFmpeg v210 saw ~2x on similar vpermb tricks)
- AVX-512 overall decode: reported ~10-20% over AVX2 on low thread counts (Ice Lake), workload-dependent
- AVX-512 ipred z1/z2/z3: keeps data in registers, uses vpermb/vpermi2b instead of memory loads
- 6-tap MC (1.4.2): AV1 spec lets many blocks use 6-tap; dedicated kernel skips 2 taps -> meaningful mc win

=== IMPLICATIONS FOR rav1d-safe (8bpc 4K AVIF STILL DECODE) ===
Stills = intra only: itx + ipred + cdef + loopfilter + looprestoration dominate. NO inter/mc/warp/refmvs.
rav1d-safe currently: AVX2+NEON safe SIMD, falls back to AVX2 for all AVX-512 paths.
Biggest gap vs dav1d 1.5.1 for STILLS = AVX-512 kernels rav1d-safe does NOT have:
  1. AVX-512 8bpc itx (existed ~1.0, expanded HBD in 1.1/1.2) -- transform-heavy, top win
  2. AVX-512 8bpc ipred z1/z2/z3 directional (1.4.0) -- intra-pred-heavy
  3. AVX-512 8bpc cdef (since ~1.0) + HBD (1.1.0)
  4. AVX-512 8bpc loopfilter HBD (1.1.0); 8bpc lf AVX-512 baseline
  5. AVX-512 ipred via vpermb register approach
Algorithmic (ISA-independent, portable to AVX2 safe-SIMD):
  - 6-tap MC kernel concept (1.4.2) -- but stills are intra, low priority
  - decode_coefs index-offset optimization (1.5.0) -- msac is 37% of rav1d-safe profile, HIGH value
  - looprestoration SGR rewrite (stack reduction; 1.5.1) -- some SSSE3 SGR speed gains portable
